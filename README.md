# Wildwood Party (Godot)

A lightweight party RPG: Mario Party-style board, D&D-style skill checks, and Pokemon-style battles. Built in Godot 4, entirely in the cloud.

Every push to `main` runs a GitHub Actions workflow that downloads the latest stable Godot, exports the game for the web, and publishes it to GitHub Pages:

**Play:** https://kmad666.github.io/Claude-test/

To open the project in the desktop editor, clone the repo and import `project.godot`.
